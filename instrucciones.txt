Revisé el PRD y el contenido del ZIP. El proyecto contiene las etapas 1–4 de seguridad: persistencia de credenciales, BCrypt, roles, login, emisión JWT y configuración parcial de rutas. La mitad faltante corresponde principalmente a:

- Validación real de JWT.
- `JwtAuthenticationFilter`.
- Registro del filtro en Spring Security.
- Endpoint `GET /api/auth/me`.
- `AuthorizationService`.
- Anti-IDOR en usuarios y tickets.
- Filtrado de eventos no publicados.
- Defensa adicional en servicios.
- Ajuste de matriz pública/protegida.
- Pruebas de regresión y propiedad.

A continuación está el parche exacto para completar esas etapas. Mantiene las 20 rutas existentes y usa `403` cuando el recurso existe pero pertenece a otro usuario; los recursos inexistentes siguen devolviendo `404`.

## 2. Completar validación JWT

```java
package com.pulsepass.security;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.Jws;
import io.jsonwebtoken.Jwts;
import io.jsonwebtoken.MalformedJwtException;
import io.jsonwebtoken.UnsupportedJwtException;
import io.jsonwebtoken.io.Decoders;
import io.jsonwebtoken.io.DecodingException;
import io.jsonwebtoken.security.Keys;
import java.time.Clock;
import java.time.Instant;
import java.util.Date;
import java.util.UUID;
import javax.crypto.SecretKey;
import org.springframework.stereotype.Service;

/**
 * Emite y valida JWT firmados con HS256.
 *
 * El JWT transporta únicamente el identificador persistente del usuario y metadatos.
 * Los roles y el estado activo se cargan desde PostgreSQL en cada solicitud.
 */
@Service
public class JwtService {

    /** HS256 exige claves de al menos 256 bits. */
    static final int MIN_KEY_BYTES = 32;

    private final JwtProperties properties;
    private final Clock clock;
    private final SecretKey key;

    public JwtService(JwtProperties properties, Clock clock) {
        this.properties = properties;
        this.clock = clock;
        this.key = buildKey(properties.secretBase64());
    }

    /** Genera un access token con sub, iss, iat, exp y jti. */
    public String generateAccessToken(Long userId) {
        if (userId == null) {
            throw new IllegalArgumentException("userId is required");
        }

        Instant now = Instant.now(clock);

        return Jwts.builder()
                .subject(userId.toString())
                .issuer(properties.issuer())
                .issuedAt(Date.from(now))
                .expiration(Date.from(now.plus(properties.accessTokenTtl())))
                .id(UUID.randomUUID().toString())
                .signWith(key, Jwts.SIG.HS256)
                .compact();
    }

    /**
     * Valida firma, algoritmo esperado, issuer, expiración, emisión, jti y subject.
     *
     * Las excepciones de JJWT deben traducirse posteriormente a 401; este servicio
     * no decide ni ejecuta reglas de negocio.
     */
    public Claims parseAndValidate(String token) {
        Jws<Claims> jws = Jwts.parser()
                .verifyWith(key)
                .requireIssuer(properties.issuer())
                .build()
                .parseSignedClaims(token);

        String algorithm = jws.getHeader().getAlgorithm();
        if (!Jwts.SIG.HS256.getId().equals(algorithm)) {
            throw new UnsupportedJwtException("Unexpected JWT algorithm: " + algorithm);
        }

        Claims claims = jws.getPayload();

        if (claims.getSubject() == null || claims.getSubject().isBlank()) {
            throw new MalformedJwtException("JWT subject is required");
        }
        if (claims.getId() == null || claims.getId().isBlank()) {
            throw new MalformedJwtException("JWT id is required");
        }
        if (claims.getIssuedAt() == null) {
            throw new MalformedJwtException("JWT issued-at is required");
        }
        if (claims.getExpiration() == null) {
            throw new MalformedJwtException("JWT expiration is required");
        }

        return claims;
    }

    /** Devuelve el identificador persistente contenido en el claim sub. */
    public Long extractUserId(String token) {
        String subject = parseAndValidate(token).getSubject();
        try {
            return Long.valueOf(subject);
        } catch (NumberFormatException ex) {
            throw new MalformedJwtException("JWT subject must be a numeric user id");
        }
    }

    public long accessTokenTtlSeconds() {
        return properties.accessTokenTtl().toSeconds();
    }

    private static SecretKey buildKey(String secretBase64) {
        if (secretBase64 == null || secretBase64.isBlank()) {
            throw new IllegalStateException(
                    "JWT secret is missing: set PULSEPASS_JWT_SECRET_BASE64");
        }

        byte[] bytes;
        try {
            bytes = Decoders.BASE64.decode(secretBase64);
        } catch (DecodingException | IllegalArgumentException ex) {
            // Nunca se incluye el valor del secreto en el mensaje.
            throw new IllegalStateException("JWT secret is not valid Base64");
        }

        if (bytes.length < MIN_KEY_BYTES) {
            throw new IllegalStateException(
                    "JWT secret is too weak: at least "
                            + MIN_KEY_BYTES
                            + " random bytes are required");
        }

        return Keys.hmacShaKeyFor(bytes);
    }
}
```

## 3. Nuevo filtro Bearer

Crear:

`src/main/java/com/pulsepass/security/JwtAuthenticationFilter.java`

```java
package com.pulsepass.security;

import io.jsonwebtoken.Claims;
import io.jsonwebtoken.JwtException;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.util.Optional;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.HttpHeaders;
import org.springframework.security.authentication.AnonymousAuthenticationToken;
import org.springframework.security.authentication.UsernamePasswordAuthenticationToken;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.context.SecurityContext;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.security.core.userdetails.UsernameNotFoundException;
import org.springframework.security.web.authentication.WebAuthenticationDetailsSource;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;

/**
 * Filtro Bearer stateless.
 *
 * - Sin Authorization continúa para que la cadena decida si la ruta es pública.
 * - Bearer inválido, vencido, manipulado o con issuer incorrecto nunca autentica.
 * - Carga el usuario actual desde persistencia, incluyendo estado activo y roles actuales.
 * - No sobrescribe una autenticación ya establecida.
 */
@Component
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private static final Logger log = LoggerFactory.getLogger(JwtAuthenticationFilter.class);
    private static final String BEARER_PREFIX = "Bearer ";

    private final JwtService jwtService;
    private final CustomUserDetailsService userDetailsService;

    public JwtAuthenticationFilter(JwtService jwtService,
                                   CustomUserDetailsService userDetailsService) {
        this.jwtService = jwtService;
        this.userDetailsService = userDetailsService;
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain) throws ServletException, IOException {
        Optional<String> token = extractBearerToken(request);

        if (token.isEmpty() || hasEstablishedAuthentication()) {
            filterChain.doFilter(request, response);
            return;
        }

        try {
            Claims claims = jwtService.parseAndValidate(token.get());
            Long userId = Long.valueOf(claims.getSubject());

            SecurityPrincipal principal = userDetailsService.loadPrincipalById(userId);

            // Un usuario desactivado pierde acceso desde el siguiente request validado.
            if (!principal.isEnabled()) {
                log.debug("JWT rejected because userId={} is disabled", userId);
                filterChain.doFilter(request, response);
                return;
            }

            // El hash no debe permanecer en el contexto de seguridad.
            principal.eraseCredentials();

            UsernamePasswordAuthenticationToken authentication =
                    UsernamePasswordAuthenticationToken.authenticated(
                            principal,
                            null,
                            principal.getAuthorities());
            authentication.setDetails(
                    new WebAuthenticationDetailsSource().buildDetails(request));

            SecurityContext context = SecurityContextHolder.getContext();
            context.setAuthentication(authentication);
        } catch (JwtException
                 | IllegalArgumentException
                 | UsernameNotFoundException ex) {
            // Se deja el contexto no autenticado. AuthenticationEntryPoint responderá 401
            // en rutas protegidas. El token nunca se escribe en logs.
            log.debug("JWT validation failed: {}", ex.getClass().getSimpleName());
        }

        filterChain.doFilter(request, response);
    }

    private Optional<String> extractBearerToken(HttpServletRequest request) {
        String header = request.getHeader(HttpHeaders.AUTHORIZATION);

        if (header == null || header.isBlank()) {
            return Optional.empty();
        }

        if (!header.regionMatches(true, 0, BEARER_PREFIX, 0, BEARER_PREFIX.length())) {
            return Optional.empty();
        }

        String token = header.substring(BEARER_PREFIX.length()).trim();
        return token.isEmpty() ? Optional.empty() : Optional.of(token);
    }

    private boolean hasEstablishedAuthentication() {
        Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
        return authentication != null
                && authentication.isAuthenticated()
                && !(authentication instanceof AnonymousAuthenticationToken);
    }
}
```

```java
package com.pulsepass.security;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.HttpMethod;
import org.springframework.security.authentication.AuthenticationManager;
import org.springframework.security.authentication.AuthenticationProvider;
import org.springframework.security.authentication.dao.DaoAuthenticationProvider;
import org.springframework.security.config.annotation.authentication.configuration.AuthenticationConfiguration;
import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.annotation.web.configurers.AbstractHttpConfigurer;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.core.userdetails.UserDetailsService;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.security.web.AuthenticationEntryPoint;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.access.AccessDeniedHandler;
import org.springframework.security.web.authentication.UsernamePasswordAuthenticationFilter;

/**
 * Declara autenticación, filtro Bearer y reglas de rutas. No contiene reglas comerciales.
 */
@Configuration
@EnableWebSecurity
@EnableMethodSecurity
public class SecurityConfig {

    @Bean
    PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder();
    }

    @Bean
    AuthenticationProvider authenticationProvider(UserDetailsService userDetailsService,
                                                  PasswordEncoder passwordEncoder) {
        DaoAuthenticationProvider provider = new DaoAuthenticationProvider(userDetailsService);
        provider.setPasswordEncoder(passwordEncoder);
        return provider;
    }

    @Bean
    AuthenticationManager authenticationManager(AuthenticationConfiguration configuration)
            throws Exception {
        return configuration.getAuthenticationManager();
    }

    @Bean
    SecurityFilterChain securityFilterChain(HttpSecurity http,
                                            JwtAuthenticationFilter jwtFilter,
                                            AuthenticationEntryPoint authEntryPoint,
                                            AccessDeniedHandler deniedHandler)
            throws Exception {
        http
                // Válido porque la API es Bearer y no usa cookies de autenticación.
                .csrf(AbstractHttpConfigurer::disable)
                .sessionManagement(sm ->
                        sm.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
                .formLogin(AbstractHttpConfigurer::disable)
                .httpBasic(AbstractHttpConfigurer::disable)
                .exceptionHandling(ex -> ex
                        .authenticationEntryPoint(authEntryPoint)
                        .accessDeniedHandler(deniedHandler))
                .authorizeHttpRequests(auth -> auth
                        // Públicas explícitas.
                        .requestMatchers(HttpMethod.POST,
                                "/api/auth/login",
                                "/api/users").permitAll()

                        .requestMatchers(HttpMethod.GET,
                                "/api/events/published",
                                "/api/events/by-artist").permitAll()

                        // Rutas operativas de eventos.
                        .requestMatchers(HttpMethod.GET,
                                "/api/events/*/tickets/paid")
                                .hasAnyRole("STAFF", "ADMIN")

                        // Pública a nivel HTTP; EventService oculta borradores y
                        // exige STAFF/ADMIN cuando el evento no está PUBLISHED.
                        .requestMatchers(HttpMethod.GET,
                                "/api/events/*").permitAll()

                        .requestMatchers(HttpMethod.GET,
                                "/api/artists/**",
                                "/api/venues/**").permitAll()

                        // Administración de eventos.
                        .requestMatchers(HttpMethod.POST,
                                "/api/events").hasRole("ADMIN")
                        .requestMatchers(HttpMethod.PATCH,
                                "/api/events/*/publish").hasRole("ADMIN")
                        .requestMatchers(HttpMethod.POST,
                                "/api/events/*/artists/*").hasRole("ADMIN")

                        // Compra limitada a USER. La propiedad del email se verifica
                        // además dentro de TicketService mediante AuthorizationService.
                        .requestMatchers(HttpMethod.POST,
                                "/api/tickets").hasRole("USER")

                        // Control operativo de entrada.
                        .requestMatchers(HttpMethod.PATCH,
                                "/api/tickets/*/use")
                                .hasAnyRole("STAFF", "ADMIN")

                        // Todo lo demás exige identidad. Las reglas de propiedad
                        // se verifican en la frontera de servicio.
                        .anyRequest().authenticated())
                .addFilterBefore(jwtFilter,
                        UsernamePasswordAuthenticationFilter.class);

        return http.build();
    }
}
```

## 5. Nuevo `AuthorizationService`

Crear:

`src/main/java/com/pulsepass/service/AuthorizationService.java`

```java
package com.pulsepass.service;

import com.pulsepass.domain.enums.EventStatus;
import com.pulsepass.domain.model.Ticket;
import com.pulsepass.domain.model.User;
import com.pulsepass.repository.UserRepository;
import com.pulsepass.security.SecurityPrincipal;
import org.springframework.security.access.AccessDeniedException;
import org.springframework.security.authentication.AnonymousAuthenticationToken;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.GrantedAuthority;
import org.springframework.security.core.context.SecurityContextHolder;
import org.springframework.stereotype.Service;

/**
 * Frontera de autorización de propiedad y privilegios.
 *
 * Nunca confía en un userId, email o rol enviado por el cliente. Compara contra el
 * identificador persistente contenido en SecurityPrincipal.
 */
@Service
public class AuthorizationService {

    private static final String FORBIDDEN =
            "No tiene permisos para realizar esta operación";

    private final UserRepository userRepository;

    public AuthorizationService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }

    /** Devuelve el principal autenticado con JWT o falla con AccessDeniedException. */
    public SecurityPrincipal currentPrincipal() {
        Authentication authentication = currentAuthentication();

        if (authentication == null
                || !authentication.isAuthenticated()
                || authentication instanceof AnonymousAuthenticationToken
                || !(authentication.getPrincipal() instanceof SecurityPrincipal principal)) {
            deny();
        }

        return (SecurityPrincipal) authentication.getPrincipal();
    }

    public void requireAdmin() {
        if (!hasAnyRole(currentAuthentication(), "ADMIN")) {
            deny();
        }
    }

    public void requireStaffOrAdmin() {
        if (!hasAnyRole(currentAuthentication(), "STAFF", "ADMIN")) {
            deny();
        }
    }

    /** El principal debe ser USER y el usuario destino debe ser el mismo persistente. */
    public void requireUserSelfPurchase(User owner) {
        SecurityPrincipal principal = currentPrincipal();
        requireRole(principal, "USER");

        if (owner == null
                || owner.getId() == null
                || !owner.getId().equals(principal.getUserId())) {
            deny();
        }
    }

    /** Propietario, STAFF o ADMIN pueden consultar un ticket. */
    public void requireTicketAccess(Ticket ticket) {
        Authentication authentication = currentAuthentication();

        if (isTicketOwner(authentication, ticket)
                || hasAnyRole(authentication, "STAFF", "ADMIN")) {
            return;
        }

        deny();
    }

    /** Cancelación: propietario o ADMIN. STAFF no hereda derechos de autoservicio. */
    public void requireTicketCancellation(Ticket ticket) {
        Authentication authentication = currentAuthentication();

        if (isTicketOwner(authentication, ticket)
                || hasAnyRole(authentication, "ADMIN")) {
            return;
        }

        deny();
    }

    /** Búsqueda directa de usuario: propio usuario o ADMIN. */
    public void requireSelfOrAdmin(User requestedUser) {
        SecurityPrincipal principal = currentPrincipal();

        if (requestedUser == null
                || requestedUser.getId() == null
                || !requestedUser.getId().equals(principal.getUserId())) {
            if (!hasAnyRole(currentAuthentication(), "ADMIN")) {
                deny();
            }
        }
    }

    /**
     * Búsqueda por email para colecciones. Si el email no existe, se compara contra
     * el email actual persistido del principal para no cambiar el comportamiento
     * de una consulta propia vacía, ni filtrar existencia a terceros.
     */
    public void requireSelfOrAdminByEmail(String email) {
        String normalized = email == null ? "" : email.trim();

        if (normalized.isBlank()) {
            deny();
        }

        User requestedUser = userRepository
                .findByEmailIgnoreCase(normalized)
                .orElse(null);

        if (requestedUser != null) {
            requireSelfOrAdmin(requestedUser);
            return;
        }

        Authentication authentication = currentAuthentication();
        if (hasAnyRole(authentication, "ADMIN")) {
            return;
        }

        SecurityPrincipal principal = currentPrincipal();
        User currentUser = userRepository.findById(principal.getUserId())
                .orElseThrow(() -> new AccessDeniedException(FORBIDDEN));

        if (!currentUser.getEmail().equalsIgnoreCase(normalized)) {
            deny();
        }
    }

    /**
     * Los eventos PUBLISHED son visibles públicamente. Los demás estados exigen
     * STAFF o ADMIN.
     */
    public void requireEventVisibility(EventStatus status) {
        if (status == EventStatus.PUBLISHED) {
            return;
        }
        requireStaffOrAdmin();
    }

    /** STAFF o ADMIN pueden ver todos los estados en búsquedas de eventos. */
    public boolean canViewAllEvents() {
        return hasAnyRole(currentAuthentication(), "STAFF", "ADMIN");
    }

    private Authentication currentAuthentication() {
        return SecurityContextHolder.getContext().getAuthentication();
    }

    private boolean isTicketOwner(Authentication authentication, Ticket ticket) {
        if (authentication == null
                || !(authentication.getPrincipal() instanceof SecurityPrincipal principal)
                || ticket == null
                || ticket.getUser() == null) {
            return false;
        }

        return principal.getUserId().equals(ticket.getUser().getId());
    }

    private void requireRole(SecurityPrincipal principal, String role) {
        boolean allowed = principal.getAuthorities().stream()
                .map(GrantedAuthority::getAuthority)
                .anyMatch(authority -> ("ROLE_" + role).equals(authority));

        if (!allowed) {
            deny();
        }
    }

    private boolean hasAnyRole(Authentication authentication, String... roles) {
        if (authentication == null || !authentication.isAuthenticated()) {
            return false;
        }

        for (String role : roles) {
            String expected = "ROLE_" + role;
            boolean found = authentication.getAuthorities().stream()
                    .map(GrantedAuthority::getAuthority)
                    .anyMatch(expected::equals);
            if (found) {
                return true;
            }
        }

        return false;
    }

    private void deny() {
        throw new AccessDeniedException(FORBIDDEN);
    }
}
```

```java
    requireText(eventCode, "eventCode");
    authorizationService.requireStaffOrAdmin();

    if (!eventRepository.existsByEventCode(eventCode)) {
        throw ResourceNotFoundException.of("Event", eventCode);
    }

    return ticketRepository.findByEventEventCodeAndStatus(eventCode, TicketStatus.PAID)
            .stream()
            .map(ticketMapper::toResponse)
            .toList();
}

@Override
@Transactional
public TicketResponse cancel(String ticketCode) {
    Ticket ticket = getTicket(ticketCode);
    authorizationService.requireTicketCancellation(ticket);

    // Conservar las reglas BR-TICKET-010 a BR-TICKET-012 existentes.
    if (ticket.getStatus() != TicketStatus.PAID) {
        throw new BusinessRuleException("Only PAID tickets can be cancelled. Ticket "
                + ticketCode + " is " + ticket.getStatus() + ".");
    }

    if (!ticket.getEvent().getEventDate().isAfter(now())) {
        throw new BusinessRuleException("Ticket " + ticketCode
                + " cannot be cancelled after the event date.");
    }

    ticket.setStatus(TicketStatus.CANCELLED);
    return ticketMapper.toResponse(ticketRepository.save(ticket));
}

@Override
@Transactional
public TicketResponse markAsUsed(String ticketCode) {
    requireText(ticketCode, "ticketCode");
    authorizationService.requireStaffOrAdmin();

    Ticket ticket = getTicket(ticketCode);

    // Conservar las transiciones existentes.
    if (ticket.getStatus() == TicketStatus.CANCELLED) {
        throw new BusinessRuleException("Ticket " + ticketCode
                + " is CANCELLED and cannot be used.");
    }

    if (ticket.getStatus() != TicketStatus.PAID) {
        throw new BusinessRuleException("Only PAID tickets can be marked as used. Ticket "
                + ticketCode + " is " + ticket.getStatus() + ".");
    }

    ticket.setStatus(TicketStatus.USED);
    return ticketMapper.toResponse(ticketRepository.save(ticket));
}
```

En `publish` y `addArtist`, inmediatamente después de obtener el evento, agregar:

```java

```

Reemplazar `findByArtist`:

```java
@Override
@Transactional(readOnly = true)
public List<EventSummaryResponse> findByArtist(String stageName) {
    requireText(stageName, "stageName");

    Artist artist = artistRepository.findByStageNameIgnoreCase(stageName)
            .orElseThrow(() -> ResourceNotFoundException.of("Artist", stageName));

    List<Event> events = eventRepository.findByArtistStageName(artist.getStageName());

    // FR-SEC-EVT-06: público solamente para eventos PUBLISHED.
    if (!authorizationService.canViewAllEvents()) {
        events = events.stream()
                .filter(event -> event.getStatus() == EventStatus.PUBLISHED)
                .toList();
    }

    return events.stream()
            .map(eventMapper::toSummary)
            .toList();
}
```

Con esto:

- Anónimo y `USER` solo ven eventos `PUBLISHED`.
- `STAFF` y `ADMIN` pueden ver otros estados.
- `GET /api/events/{eventCode}` sigue existiendo para eventos publicados.
- Los borradores no se exponen por una ruta pública.

## 11. Pruebas que deben añadirse o completarse

### `JwtServiceTest`

Debe cubrir:

- Firma correcta.
- `sub`, `iss`, `iat`, `exp` y `jti`.
- Expiración.
- Issuer incorrecto.
- Token manipulado.
- Token vacío.
- Algoritmo inesperado.
- Clave Base64 inválida.
- Clave menor a 32 bytes.
- `extractUserId()` con subject no numérico.

### `JwtAuthenticationFilterTest`

Usar `MockHttpServletRequest`, `MockHttpServletResponse` y `MockFilterChain`, con los filtros habilitados. Cubrir:

- Sin header continúa sin autenticar.
- Bearer válido crea `SecurityPrincipal`.
- Bearer vencido/manipulado no autentica.
- Usuario inactivo no autentica.
- No sobrescribe una autenticación ya existente.
- No registra ni expone el token.

### `SecurityRulesTest` con MockMvc

No usar:

```java
@AutoConfigureMockMvc(addFilters = false)
```

Casos mínimos:

- Anónimo `GET /api/events/published` → `200`.
- Anónimo `GET /api/venues/active` → `200`.
- Anónimo `POST /api/events` → `401`.
- `USER` `POST /api/events` → `403`, sin invocar `EventService`.
- `ADMIN` `POST /api/events` válido → `201`.
- Login correcto → `200` con `accessToken`, `Bearer` y `expiresIn`.
- Login con contraseña incorrecta → `401`.
- Token alterado en ruta protegida → `401` con `ErrorResponse`.
- Token válido → acceso según rol.
- `USER` intenta `PATCH /api/tickets/{code}/use` → `403`.
- `STAFF` intenta `PATCH /api/tickets/{code}/use` → `200` cuando el servicio lo permite.

### Pruebas de propiedad

Con usuarios reales o mocks adecuados:

- Andrea compra con su email → permitido.
- Andrea compra con el email de Carlos → `403`, sin crear ticket.
- Andrea consulta ticket de Carlos → `403`.
- Andrea cancela ticket propio → respuesta del servicio.
- Andrea cancela ticket de Carlos → `403`.
- Carlos consulta sus propios tickets → `200`.
- Andrea consulta tickets de Carlos → `403`.
- `STAFF` consulta ticket operativo → permitido.
- `STAFF` cancela ticket → `403`.
- `ADMIN` publica evento → permitido.
- `USER` publica evento → `403`.
- Usuario desactivado con token anteriormente válido → `401`.
